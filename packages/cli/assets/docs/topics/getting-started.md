# Getting started

Specplane stores requirements as Markdown specifications. You can use it for ordinary work on any branch; a managed plan is optional. A specification's review status and its implementation status describe different things.

Initialize repository guidance and configuration explicitly:

```sh
specplane init
specplane spec list
specplane validate
```

Review the configuration and authorship policy before changing a specification. Initialization prepares repository assets; copying files does not establish that a host plugin is installed or enabled.

This documentation bundle is being prepared against the current implementation. Offline CLI docs lookup and guidance refresh are planned integration work and are unavailable until their handlers ship. Read the packaged topics directly in the meantime. Claude native handlers and Codex background execution have no live certification here.
