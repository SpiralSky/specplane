It acquires repository/plan/checkout leases (dry-run inspects only), checks unfinished Git operations and HEAD/index/output preimages, verifies the branch and owned bytes, and preserves unrelated implementation staging. Captured HEAD-based validation of the complete plan/spec/ADR and selected plan step/HANDOFF inventory is needed to remove that refusal safely; this is implementation work, not a product/spec blocker.
